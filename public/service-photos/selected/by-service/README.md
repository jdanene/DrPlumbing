# Photos by service

Each service folder contains its website subcategories:

- [General plumbing](general-plumbing/)
- [Water heaters](water-heaters/)
- [Drain and sewer](drain-and-sewer/)
- [Water filtration](water-filtration/)
- [Heating and cooling](heating-and-cooling/)
- [Boilers](boilers/)
- [On-the-job photos](about/on-the-job/)

The images are reviewed candidates, not the final website selection. A category
with no supported match contains only its README. `system-overview` holds relevant
equipment that does not establish a more specific subtype or activity.

Each filename starts with its catalog ID and retains the original filename stem.
The same image may appear in several folders when it visibly supports each subject.
Originals remain in `public/service-photos` at the project root.

Open the [review gallery](../../../../design/photo-classification/index.html),
[classification workflow](../../../../design/photo-classification/README.md),
[coverage table](../../../../design/photo-classification/coverage.csv), or
[identification questions](../../../../design/photo-classification/review-questions.md).

The existing website photos outside this folder remain for compatibility. Their
earlier filenames and page assignments are not the classification source of truth.
